# Project Statement

## Project Title

Smartdoc - Computer Vision Based Document Scanner & Image Quality Analyzer

## Problem Statement

Taking photographs of documents using a mobile phone can produce images with perspective distortion, uneven lighting, blur, noise, and low contrast.

Smartdoc - Computer Vision aims to automate the document-processing workflow using Computer Vision techniques.

## Scope

The project focuses on processing a single document photograph.

The system performs:

- Document boundary detection
- Corner detection
- Perspective correction
- Image enhancement
- Adaptive thresholding
- Image quality analysis
- Result generation

## Target Users

The intended users include:

- Students
- Teachers
- Office users
- Researchers
- Anyone who needs to digitize photographed documents

## High-Level Features

1. Document Detection
2. Perspective Correction
3. Image Enhancement
4. Image Quality Analysis
5. Automated Testing
6. Command-Line Processing

## Expected Outcome

The system should transform a photographed document into a cleaner and more readable digital image while providing basic numerical information about image quality.

## Computer Vision Techniques

The project applies:

- Image preprocessing
- Grayscale conversion
- Gaussian filtering
- Canny edge detection
- Contour detection
- Polygon approximation
- Perspective transformation
- CLAHE
- Adaptive thresholding
- Laplacian variance analysis

## Project Type

Academic Computer Vision project developed according to the VITyarthi Build Your Own Project requirements.
